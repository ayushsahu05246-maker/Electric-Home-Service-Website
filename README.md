# ⚡ Electric Home Service Website

A modern service-booking platform that connects customers with professional electricians through an easy-to-use web interface. The platform streamlines service requests, booking management, and customer interactions.

---

## 🚀 Features

- 👨‍🔧 Electrician Service Booking
- 📅 Appointment Scheduling
- 👤 Customer Management
- 🔐 Admin Dashboard
- 📱 Fully Responsive Design
- ⚡ Fast and User-Friendly Interface
- 🗂️ Booking Management System
- ☁️ Database Integration
